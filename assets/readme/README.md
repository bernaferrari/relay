# README images

Keep interface screenshots at **2× their display size**: a 1280×900 workspace
should produce a 2560×1800 image. Capture the rendered interface at that density;
enlarging an existing screenshot cannot restore text detail.

Encode UI captures as lossless WebP without resizing. The demo uses four frames
at their original 2368×984 resolution; the banners retain their 2560×1104 originals.
Use only the owned demo workspace for public captures.

The main README links workspace screenshots to the full-resolution files so readers
can open and zoom them.
