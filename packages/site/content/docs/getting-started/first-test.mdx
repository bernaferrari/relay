---
title: Your first test
description: Record one flow in your own website, run it again, and review what Relay saw. No model key needed.
---

Your first test is one short journey in your own website: something you check by hand today, like adding an item to a cart and reaching checkout. Record it once, and Relay can repeat it whenever you want.

Relay currently runs from source. No published npm package or desktop installer is required.

## 1. Get Relay running

Install [Node.js 24 or newer](https://nodejs.org/en/download), [pnpm](https://pnpm.io/installation), and Chrome, Chromium, or Edge. Then:

```bash title="Terminal"
git clone https://github.com/bernaferrari/relay.git
cd relay
pnpm install
pnpm doctor -- --web
pnpm ensure:serve
pnpm dev:web
```

Follow the doctor's instructions if a prerequisite is missing. For an unusual browser installation, set `RELAY_BROWSER_EXECUTABLE` to its absolute path before starting the service. Prefer a window of its own? Use `pnpm dev:desktop` instead of `pnpm dev:web`.

## 2. Record one flow

In Relay, choose **New test**, pick **Website**, and enter your site's address (a local one like `localhost:3000` works). Relay opens a fresh browser.

Click through the journey the way you normally would. Each action becomes a step. Add a **check** where something must be true, like "the order total is visible", and a **screenshot** where you want to look at the screen later. When you're done, choose **Stop and review**, then **Save**.

No account, model key, Android tools, or iOS tools are needed for recorded steps.

## 3. Run it again

Open the test and press **Run**. Relay repeats every step in a fresh browser and shows each one with its timing and the screen it reached. If a check fails, it says what it **expected** and what it **saw**, next to the screenshot.

A passing check is not the same as someone approving how the screen looks. That is a [screenshot review](/docs/workflows/review) decision.

## 4. Repeat it anywhere

The same saved test runs from the command line and from coding agents:

```bash
pnpm relay run "Checkout" --device browser
```
