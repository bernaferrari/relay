## Install from source

You need **Node.js 24+**, **pnpm**, and Git. Platform tools depend on what you want to test; a website does not require Android or iOS tooling.

```bash
git clone https://github.com/bernaferrari/relay.git
cd relay
pnpm install
pnpm doctor
```

The doctor reports missing prerequisites. Address the ones for your intended target first.

## Open the workspace

Choose one interface:

```bash title="Desktop app"
pnpm dev:desktop
```

```bash title="Web interface"
pnpm dev:web
```

The launchers start or reuse the local service. Keep the interface process running while you use it. The web command prints the local URL. Both interfaces use Relay's local service and the same workspace operations. Use the URL printed by your process; the port can differ when another service is already running.

## Choose a target

- **Website:** use a supported local browser. See [browser setup](/docs/devices/browser).
- **Android:** connect a device over USB or start an emulator. See [Android setup](/docs/devices/android).
- **iOS:** use a Mac with Xcode and a simulator or a connected device. See [iPhone and iPad setup](/docs/devices/ios).

Open **Devices** and check that the preview shows the app and account you intend to use. A screenshot alone does not prove that interactive controls are available.

## Add a model key when you need one

Recorded steps replay without a model. Describing tests and model-assisted actions do.

Open **Settings → Advanced** and add your OpenRouter key, or set it in your shell before starting Relay:

```bash
export OPENROUTER_API_KEY="your-key"
pnpm dev:web
```

The placeholder is not a real key. Prefer the Settings form to avoid putting a real key in shell history. Keep the key out of version control. Model requests go to the configured provider; deterministic recorded input and visible-text checks do not need a model, but description-based steps and model-assisted checks do.

If Relay was already running, setting an environment variable in a new shell does not update that process. Save the key in Settings, or restart the service with the new environment after active recordings and Runs finish.
