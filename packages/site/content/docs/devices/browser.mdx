## Check the prerequisites

Install Chrome, Chromium, or Edge on the machine running Relay. From the repository:

```bash
pnpm doctor -- --web
```

If your browser is installed in an unusual location, set `RELAY_BROWSER_EXECUTABLE` to its absolute executable path before starting Relay.

## Start with the local demo

[Your first test](/docs/getting-started/first-test) uses a controlled local website. It is the simplest way to confirm browser execution and evidence collection without sign-in or a model key.

## Use your own website

Open **Tests → New test**, choose the website target, and enter its address. Describe one outcome, or leave the description empty to record manually.

For journeys behind sign-in, [save the intended website account](/docs/workflows/accounts), then select it in the run setup. Confirm its identity before recording. A personal browser session is not automatically Relay’s controlled context.

## Explore without recording

Open a saved browser, or choose **Workspace** to use several browsers side by side. Each browser keeps its own account. You can navigate and interact before deciding to record a Test.

The **⋯ browser menu** beside the address contains:

- **Find on page**: search visible page text, then move between matches. Press Escape to close.
- **Zoom**: change the controlled page’s size or reset to 100%.
- **History**: search and reopen the current tab’s navigation entries. This is not your personal browser’s history.
- **Save screenshot**: download the current preview as a PNG.

Shortcuts apply to the browser you are focused on: **⌘F / Ctrl+F** for Find, **⌘Y / Ctrl+H** for History, and **⌘ / Ctrl** with **+**, **−**, or **0** for zoom.

Closing a workspace tile shows **Undo** for eight seconds. Undo restores the same live browser and its position. The saved browser remains in your library after its tile is removed.

## Replay in the right context

Use the saved Test's Run settings to choose its browser setup. A page you happen to have open is not automatically the same execution context as a controlled Test run.

Keep viewport and language stable for the first qualification. Add other configurations through [Plans and Data sets](/docs/workflows/data-sets) after the journey works.

## Keep evidence small

New recordings and Runs use lightweight evidence. Screenshots, structure, and diagnostics are retained without automatic video. Enable **Include video** in [Evidence & privacy](/docs/reference/evidence) when motion or transitions matter.

If Relay cannot open or control the browser, follow [troubleshooting](/docs/reference/troubleshooting). Do not repeatedly create browser setups to work around one broken connection.
