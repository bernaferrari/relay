---
title: Connect Android
description: Use an Android phone, tablet, or emulator with Relay's live preview and recorder.
---

## Connect the device

Install Android platform tools so `adb` is available. On a physical device, enable Developer options and USB debugging, connect it over USB, and accept the device's debugging authorization for your computer.

For an emulator, start it through your Android tooling before opening Relay.

```bash
pnpm doctor
```

## Check it in Relay

Open **Devices** and select the intended device. Confirm the app name, current screen, and account in the preview. Keep the device unlocked and awake while recording or running.

If several devices are available, choose the exact device rather than relying on a generic Android selection. A device already held by a recording or Run should be allowed to finish.

## Record one journey

Choose **Phone or tablet** in New test, select your device and app, then [record a short flow](/docs/workflows/recording).

Inspect controls when available. A named or identified control is more robust than a coordinate tap. Coordinate steps need requalification on another viewport or language.

## Run and inspect

[Replay the saved Test](/docs/workflows/running) and inspect the screen path and result of each step. A screenshot showing the right app is helpful, but the replay's checks establish whether the saved flow worked.

If another app or automation session takes over the device, stop and restore the intended screen before continuing. Do not keep sending inputs to an uncertain target.

## Reconnect when needed

Use **Reconnect** in Devices, then check the preview. If the device no longer appears, inspect its cable, USB authorization, and `adb` connection. The [troubleshooting guide](/docs/reference/troubleshooting) separates device availability from app failures.
