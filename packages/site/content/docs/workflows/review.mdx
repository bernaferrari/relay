Execution and review answer different questions. A check may pass while an image still needs a human decision about its appearance.

<WorkflowDiagram />

## Open the captured evidence

Open the Run's Result and choose **Screenshots**, or open its report. Select a captured step to inspect the image, then use the enlarged view when details are too small.

Check that you are reviewing the intended Run, target, account, and configuration. A screenshot from another attempt is not interchangeable evidence.

## Make a decision

| Decision               | Use it when                                                |
| ---------------------- | ---------------------------------------------------------- |
| **Looks correct**      | You inspected the image and its appearance is acceptable.  |
| **Report issue**       | You can identify a visible problem in the captured screen. |
| **Need more evidence** | The image does not show enough to decide.                  |

Only approve the image or explicit selection you have actually inspected. A missing capture cannot be approved; rerun to collect new evidence.

## Choose a reference explicitly

**Looks correct** accepts the selected capture for this Run. **Accept as reference for future runs** also chooses it as a reference for later visual comparisons. Use the reference action only when the image represents the intended design and configuration.

A later match to an approved reference is not a new human inspection. Keep the reference policy and any remaining review obligations visible.

## Compare configurations

For a Plan, use its Gallery to compare captures across the selected devices or data sets. Inspect a small scope first, then expand after the journey reliably reaches the intended checkpoint.

If a decision save is interrupted, check the saved-decision count. Refresh before retrying an unconfirmed decision. Already acknowledged decisions remain saved.

## Share the result

Open the Run report and choose **Export evidence**, then **Save evidence pack**. Inspect its screenshots and logs before sharing, since they can contain app or account information.

An export is a snapshot of that Run and the review decisions at export time. Export again if you make more decisions later.

## Keep the meanings separate

**Completed** describes execution. **Accepted** describes a review decision. **Missing** describes evidence availability. None should silently stand in for another.

For storage choices and optional collection, see [Evidence & privacy](/docs/reference/evidence).
